# Agent guide

This Product runs on the Kit. Read only what the task needs:

- `CHARTER.md`: what this Product is for, its Areas and their ranked Features.
- `CONTEXT.md`: the vocabulary. Use these words in code and prose.
- `docs/adr/`: decisions that are hard to reverse.
- `.agents/kit.json`: the commands that prove code works.
- `.agents/standards.md`: where this Product differs from the Kit's standards.
- `.agents/cycles/<area>/`: the running Cycle's PRD, Issues and progress.
- `data/`: Sample data, read-only. Write results only to `data/out/`.

Phases: an optional Brainstorm, then a Charter grill (once at the start, and again when an Area runs out of Features), then per Cycle: Pick, Research, Prototype, Plan, Split, Build, QA, Close.
