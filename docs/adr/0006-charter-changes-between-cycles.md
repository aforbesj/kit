# The Charter changes only between Cycles

Only a Charter grill or a retro edits `CHARTER.md`, and never during a Cycle. A Charter grill can run again after the first, usually after a Brainstorm when an Area runs out of Features, to add Features or widen scope as we learn. This replaces "only a retro edits it". A Product is never done just because its Features are, but changing the Charter mid-Cycle would move the goalposts the PRD is locked against.
